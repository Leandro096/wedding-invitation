# Imágenes del Proyecto

Este directorio contiene las imágenes necesarias para la landing page de boda.

## Imágenes requeridas:

- `hero-bg.jpg` - Imagen de fondo para la sección principal (recomendado: 1920x1080px)
- `couple-photo.jpg` - Foto de la pareja (recomendado: 800x800px)  
- `decorative-element.png` - Elemento decorativo opcional (recomendado: 200x200px, fondo transparente)

## Recomendaciones:

- Usa imágenes de alta calidad (al menos 1MB para la imagen hero)
- Las imágenes deben estar optimizadas para web
- Formatos recomendados: JPG para fotos, PNG para elementos con transparencia
- Considera usar imágenes con tonos cálidos que complementen la paleta de colores configurada

Para cambiar las imágenes, simplemente reemplaza los archivos en este directorio o actualiza las rutas en el archivo `src/data/wedding-config.json`.
